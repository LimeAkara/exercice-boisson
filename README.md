# Business case : Distributeur de boisson 

# Contexte : 

Un client fictif gère des distributeurs de boissons sur des quais de gare. Un employé passe une fois par semaine recharger les machines. Cet employé indique régulièrement que la machine était vide, mais sans préciser quels produits sont vides.

# Problématique : 

Le client veut savoir :

- Les gains qu'il pourrait avoir si les produits n'étaient pas en rupture
- Est ce que ces gains sont assez rentables pour faire déplacer l'employé deux fois par semaine au lieu d'une fois ?
